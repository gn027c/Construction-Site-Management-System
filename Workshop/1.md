Nhóm trưởng đại diện nộp bài tập cho nhóm:
1. Định tên file Report nộp bài như sau: Workshop1_Group_Topic.docx. Ví dụ Workshop1_Group1_Topic1.docx. (Có thể nộp theo định dạng .docx hoặc .pdf)
2. Định tên file Code nộp bài như sau: Workshop1_Code_Group_Topic.zip. Ví dụ Workshop1_Code_Group1_Topic1.zip.
3. Nội dung cần thực hiện
- Code: Khai báo lớp cơ bản: các thuộc tính Constructor, Getters/Setters và thêm điều kiện validation
- Report: Hoàn thành mục 1 và 2
